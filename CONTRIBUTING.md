
> **PANORAFUS.AI** — Eschatology-Centered Contribution Standard

# Contributing to PANORAFUS.AI

All contribution sessions in this repository must stay within an eschatology-centered scope.

## Required Theological Framing

Every contribution must clearly reflect both points below:

1. **Curse of sin** is presented in biblical context.
2. **Remedy for sin** is presented as the governing emphasis.

If both are not present, the session is out of scope for this repository.

## Session Scope Rule

For issues, pull requests, discussions, and review sessions:

- Keep the primary topic in biblical eschatology.
- Explicitly state the eschatology focus in your summary.
- Avoid unrelated doctrinal tangents that do not serve the eschatology topic.

## Submission Checklist

Before submitting, confirm:

- [ ] Session topic is explicitly eschatology.
- [ ] Content includes curse-of-sin context.
- [ ] Content prioritizes remedy-for-sin proclamation.
- [ ] Title/summary reflects eschatology scope.
